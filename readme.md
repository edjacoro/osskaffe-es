# OSS Kaffe

## Abrir con sincronizacion Bistrosoft

1. Ejecutar `iniciar-app.cmd`.
2. Ingresar el usuario y la contrasena de Bistrosoft cuando se soliciten.
3. Mantener abierta la ventana de PowerShell mientras se usa la aplicacion.

La clave se mantiene solo en memoria y no se guarda en archivos ni en el navegador.
Finanzas sincroniza automaticamente las ventas recientes cada 30 segundos. El boton
`Sincronizar ahora` recarga el mes seleccionado completo.

La importacion manual de Excel/CSV queda disponible como respaldo.
